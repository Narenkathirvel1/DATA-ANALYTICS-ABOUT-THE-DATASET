# INTRODUCTION TO DATA ANALYTICS

## What is Data Analytics?

Data Analytics is the systematic process of collecting, organizing, cleaning, processing, and analyzing data to obtain meaningful insights.

Raw data may not always be useful directly. Therefore, different techniques and tools are used to transform raw data into understandable information.

### Basic Steps in Data Analytics

1. **Data Collection**
   Gathering data from different sources.

2. **Data Storage**
   Storing the collected data in databases or files.

3. **Data Cleaning**
   Removing errors, duplicates, and missing values.

4. **Data Processing**
   Organizing and transforming data into a suitable format.

5. **Data Analysis**
   Identifying patterns and relationships.

6. **Data Visualization**
   Presenting results using graphs, charts, and dashboards.

7. **Decision Making**
   Using the results to solve problems and improve performance.

### Importance

Data Analytics is used in business, healthcare, education, finance, engineering, Artificial Intelligence, and many other fields.

# ABOUT THE DATASET

## What is a Dataset?

A dataset is a collection of related information organized for analysis.

Datasets can contain information about:

* Students
* Customers
* Products
* Employees
* Patients
* Financial transactions
* Weather conditions
* Sensor readings

A dataset is commonly arranged in the form of **rows and columns**.

### Example Student Dataset

| Student ID | Name  | Age | Department | Marks |
| ---------- | ----- | --- | ---------- | ----- |
| 101        | Kumar | 18  | ECE        | 85    |
| 102        | Arun  | 19  | CSE        | 90    |
| 103        | Ravi  | 18  | EEE        | 78    |
| 104        | Siva  | 18  | IT         | 88    |

In this dataset:

* Each **row** represents one student.
* Each **column** represents a characteristic.
* Each complete entry is called a **record**.
* The characteristics are called **attributes** or **features**.

Datasets are essential because they provide the input required for analysis and Machine Learning.

---

# DATASET STRUCTURE AND COMPONENTS

## Components of a Dataset

### 1. Rows

Rows represent individual records or observations.

For example, one row in a student dataset represents one student.

### 2. Columns

Columns represent different properties or attributes.

Examples include:

* Student ID
* Name
* Age
* Department
* Marks

### 3. Attributes

Attributes describe the characteristics of an object.

For example, the age and marks of a student are attributes.

### 4. Variables

A variable is a value that can change between different records.

For example:

* Age may vary from student to student.
* Marks may vary from student to student.

### 5. Records

A record contains complete information about one observation.

### 6. Features

Features are the input variables used for analysis or prediction.

For example, in a Machine Learning model predicting student performance, attendance and study hours may be used as features.

A well-organized dataset improves the speed, accuracy, and reliability of data analysis.

# TYPES OF DATASETS

## Types of Data

### 1. Numerical Data

Numerical data contains numbers that can be measured or calculated.

Examples:

* Age
* Marks
* Salary
* Temperature
* Height

### 2. Categorical Data

Categorical data represents groups or categories.

Examples:

* Department
* Gender
* City
* Product Category

### 3. Structured Data

Structured data follows a predefined format, usually rows and columns.

Examples:

* Excel files
* SQL databases
* Student records

### 4. Semi-Structured Data

Semi-structured data has some organization but does not follow a strict tabular format.

Examples:

* JSON
* XML
* HTML

### 5. Unstructured Data

Unstructured data does not have a predefined format.

Examples:

* Images
* Videos
* Audio files
* Social media posts
* Text documents

Understanding the type of dataset helps analysts choose suitable methods and tools.

# DATA CLEANING AND PREPROCESSING

## Importance of Data Cleaning

Raw datasets may contain errors and inconsistencies. Before performing analysis, the dataset must be cleaned and prepared.

### Common Problems

* Missing values
* Duplicate records
* Incorrect values
* Typographical errors
* Inconsistent formats
* Outliers

### Data Cleaning Techniques

#### 1. Handling Missing Values

Missing values can be removed or replaced using:

* Mean
* Median
* Mode

#### 2. Removing Duplicate Data

Repeated records are identified and removed.

#### 3. Correcting Errors

Incorrect values and spelling mistakes are corrected.

#### 4. Data Transformation

Data is converted into a suitable format for analysis.

#### 5. Normalization

Numerical values are scaled to a common range.

#### 6. Data Validation

The dataset is checked to ensure that the information is correct and meaningful.

Data preprocessing improves the quality of the dataset and helps produce accurate analytical results.
